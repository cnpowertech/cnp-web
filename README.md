# 시앤파워텍 웹사이트

정적 다중 페이지 회사 홈페이지입니다. `dist/`를 웹 루트로 서비스합니다.

로컬 미리보기:

```sh
python3 -m http.server 5180 --directory dist
```

## GitHub Pages 배포

GitHub Pages의 배포 원본을 `dist/`로 설정합니다. 모든 내부 링크와 에셋 경로는 저장소 하위 경로에서도 동작하도록 상대 경로로 구성되어 있습니다.

## 제품 첨부파일 관리

- 제품 상세 팝업의 `자료 관리`에서 `admin / admin`으로 로그인합니다.
- 첨부파일은 별도 서버 없이 브라우저의 IndexedDB에 저장됩니다.
- 등록한 파일은 같은 브라우저에서만 조회·다운로드·삭제할 수 있으며 다른 기기나 브라우저와 동기화되지 않습니다.
- 브라우저 데이터를 삭제하면 등록한 첨부파일도 함께 삭제됩니다.
- 정적 사이트의 관리자 로그인은 편의 기능이며 서버 기반 인증과 같은 보안 수준을 제공하지 않습니다.
